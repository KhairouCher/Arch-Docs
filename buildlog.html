    What the ratings mean
    Importance
    Critical: money, balances or the clean image can be wrong, or the platform cannot be used. High: blocks other tasks, or a launch requirement with a risk to data, money or the clean image. Medium: required for launch, but nothing else waits on it. Low: nice to have, or only needed after launch.
    Time
    Rough working time for one person, including tests and a check on screen: up to 1 day, 2 to 3 days, about 1 week, 2 weeks or more.
    Kind
    Correction: something wrong or misleading today, done first. Improvement: everyone gets it. Optional feature: some buyers want it. UI polish: how it looks and feels.
    Order
    Within one importance level: corrections first, then tasks that unblock others, then shorter before longer. A rating is never changed silently. If it changes, the note says why. Marking a task done comes with a History entry, which the note links.
